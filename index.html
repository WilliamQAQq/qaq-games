ℹ️ 关于

QAQ 游戏中心 是一个纯静态网站：打开 index.html 就能玩，或部署到 GitHub Pages / Netlify / Vercel 对外分享。

  • 📁 index.html / style.css / js/app.js / js/games.js —— 前端全部，无需构建
  • 📁 server/proxy-server.js —— 可选 Node 后端，提供真正的内容转发代理
  • 🎮 最高分用 localStorage 保存在本地，不上传

本地运行

双击 index.html 直接打开
# 或启动本地服务器（推荐，代理更稳定）：
python -m http.server 8080
# 浏览器打开 http://localhost:8080

# 启动后端代理（可选）：
cd server && npm install && node proxy-server.js
# 再在代理页选择「本地后端」

Cloudflare 代理部署（3分钟，iPad 必看）

1. 打开 dash.cloudflare.com → Workers → Create → 粘贴 server/cloudflare-worker.js → Deploy
2. 得到 https://qaq-proxy.xxx.workers.dev
3. 回到本站 → 在线代理 → 节点选「Cloudflare自建」→ 填入地址 → 保存
4. 以后访问都走 CF 全球边缘节点，自动去 X-Frame-Options 防嵌入头

# 想加密码/白名单：改 worker 顶部 ACCESS_KEY / ALLOW_LIST 后重新 Deploy

上架 GitHub（给学校 iPad 用）

# 本目录已含 Pages 自动部署工作流，跟着敲：
git init && git add -A && git commit -m "qaq games"
gh repo create qaq-games --public --source=. --push
# 或手动：GitHub 建空仓库 → 把本目录文件全传上去
# 然后 Settings → Pages → Source 选 "GitHub Actions"
# 得到 https://你的用户名.github.io/qaq-games/ → iPad Safari 打开 → 分享 → 添加到主屏幕
# 全程 HTTPS，支持离线（已内置 Service Worker），断网也能玩 8 款游戏
